## 1. 完成内容

1. **运行时可见特征采样** (`src/engine/tree/branch_induct.ts`):
   - 引入 `MatchTrace` 数据结构，完整记录单局的 `roundScores` 以及各回合真实产生的 `BranchDecision`（`handIds`、`handBadges`、`boardIds`）。
   - 重构 `sampleFromTrace`，严格根据实际发生的决策特征调用 `recognizeArchetype`；未作出决策或提前结束的回合不产生样本，坚决不回退到全卡组特征。
   - 增加 `oppMatchesObserved`，结合静态预选与采样轨迹确认对手实际命中情况。

2. **一局多回合结果复用** (`src/engine/tree/branch_induct.ts`):
   - 构建 `MatchSimulationCache`，缓存 key 为 `${treeFp}::${oppKey}::${side}::${seed}`。
   - 对每个 `(candidate, opponent, side, seed)` 只执行一次 `playSpecVsSpec`，一次性生成 1-5 回合结果与轨迹。
   - R1-R5 样本生成与崩盘诊断完全复用同一批轨迹缓存，消除了重复的底层模拟调用。

3. **搜索集 / 验证集分离与最低改善门槛** (`src/engine/tree/branch_induct.ts`):
   - 搜索阶段采用 `searchSeedBase`（默认 2000），最终采纳验证采用独立的 `validationSeedBase`（默认 9000）。
   - 增加显式改善门槛验收：`afterVal.undefeated >= beforeVal.undefeated + 0.05` 且净负场不增加时才标记 `improved: true`，有效抑制小样本过拟合。
   - 保持 `optimizeFormation` 返回数据兼容原有接口，并扩展 `searchValidation` 详细字段。

4. **经验库结构版本隔离与容错** (`src/engine/tree/search_experience.ts`):
   - 实现 `computeTreeFingerprint`（FNV-1a 确定性指纹），并将 `treeFingerprint` 融入 `replaceKey` 与 `moveKey`。
   - 树结构变更后，相同修改操作不会被旧指纹记录错误拦截。
   - 增强 `ExperienceBank.load()` 对损坏或旧格式 JSON 的容错解析与优雅降级。
