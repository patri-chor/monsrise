# T011 Acceptance - First-Four Bundle Seed Variant and Tree Optimization

## Decision

Rejected for two bounded follow-ups. The first-four mutation and fixed-panel screening stages are accepted as valid evidence, but the task cannot be accepted as a complete cycle because tree optimization was correctly blocked by a missing tree-domain interface, and its focused test violated output isolation.

## Accepted Stage Evidence

- The seed manifest resolves exactly four bundle-order seeds: `泉水剑`, `坚果救星`, `全二冲`, and `经典救星`.
- The panel resolves exactly eight unique formations: bundle first seven plus `壕炸金猴`.
- Each seed received six bounded attempts: ten valid candidates total, with per-seed acceptance/duplicate/structural-rejection statistics persisted.
- Eight-panel, both-side screening used two workers and retained six candidates under the 25% exploration-floor/maximum-six policy.
- `npx vite-node tests/first_four_generation.test.ts` passes 5/5 and confirms active-library and production dataset byte identity.
- The optimizer interface audit is correct: `optimizeFormation` traverses `FORMATION_LIBRARY` internally and cannot receive the fixed eight-opponent panel. Per T011, execution stopped before any candidate tree optimization.

## Blocking Findings

1. **Tree-domain prerequisite missing.** The existing public optimizer needs a backwards-compatible fixed-panel option before generation can perform the requested candidate tree optimization. This must be handled by the tree decision owner; generation must not modify the optimizer algorithm.

2. **P1 output-isolation violation.** During `tests/first_four_generation.test.ts`, importing/executing the retention path writes `reports/new-formation-pilot/retention.json` and `retention.md`, as shown by the CLI output. T011 permits output only below `reports/new-formation-generation/first-four-cycle/`; test activity must use a temporary output directory and must not invoke production CLI side effects.

## Follow-up

- T012 corrects generation-side test/import output isolation and must preserve the accepted first-four screening artifacts.
- After the tree domain publishes the fixed-opponent optimizer interface, a later generation task may resume T011's retained six candidates without regenerating or re-screening them.
