## 4. Tree Optimizer Interface Missing Diagnosis

- **检查模块**: [`src/engine/tree/branch_induct.ts`](file:///d:/develope/monsrise1/src/engine/tree/branch_induct.ts)
- **现有函数签名**:
  ```typescript
  export function optimizeFormation(
    BundleAI: any,
    src: Formation,
    gamesPerOpp: number,
    options?: { searchSeedBase?: number; validationSeedBase?: number }
  ): OptimizeFormationResult | null
  ```
- **缺失能力**: 现有实现内部写死遍历 `for (const opp of FORMATION_LIBRARY)`，不支持传入 `opponents?: Formation[]` 限制在固定 8 对手评估面板。
- **请求 tree 域扩展接口签名**:
  ```typescript
  export function optimizeFormation(
    BundleAI: any,
    src: Formation,
    gamesPerOpp: number,
    options?: {
      opponents?: Formation[]; // 允许指定 fixed opponent panel
      searchSeedBase?: number;
      validationSeedBase?: number;
    }
  ): OptimizeFormationResult | null
  ```
