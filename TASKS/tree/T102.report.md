1. **权威产品检查点与单回合续玩 (`Authoritative Checkpoint Continuation`)**：

   - 从真实对局中捕获 earliest loss round $R$ 的 pre-R Checkpoint；

3. **可执行分支编译与策略选择 (`Executable Branch Runtime & Warm Start`)**：
   - 将探索得出的正向分支编译挂载为 `EvolFormation` AST 节点（`attachExecutableBranchesToEvol`）；

   - 实现相同标签精确复用 (`EXACT_CASE_BRANCH`) 与相似标签热启动 (`Warm Start`)；
4. **安全合并与历史剪枝 (`Safe Prefix Merge & Pruning`)**：
   - 仅对共享相同执行前缀且经原 Case 验证的分支进行前缀合并；
