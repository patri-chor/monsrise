## 1. 任务目标与执行概要 (Mission & Execution Overview)

本任务（T126）修复并确立了 **第二代优化器闭环中真实策略决策轨迹（`ProductStrategyDecisionTrace`）的判定契约**：
1. **策略决策轨迹契约 (`ProductStrategyDecisionTrace`)**：
   - 在产品对局执行层（`play_full_game.ts`）与产品运行器（`product_match_runner.ts`）中增加标准的策略决策轨迹采集支持：
     ```ts
     export interface ProductStrategyDecisionTrace {
       round: number;
       side: 1 | 2;
       selectedNodeId?: string;
       selectedBranchId?: string;
       deploymentIntentIds: string[];
       acceptedDeploymentIds: string[];
     }
     ```
2. **严谨的 Branch Selected 匹配与候选独立评测**：
   - 彻底废除基于“存活至分叉回合”或“比分变化”的伪启发式判断；
   - `cycle/pilot.ts` 中严格依据以下三位一体条件判定分支是否真正被策略选中：
     ```text
     trace.side == target side
     AND trace.round == candidate.executableBranch.forkRound
     AND (trace.selectedBranchId == candidate.executableBranch.branchId OR trace.selectedNodeId == candidate.executableBranch.branchId)
     ```
   - 未命中的对局标记为 `branchSelected: false, classification: 'NOT_SELECTED'`，写入证据但严格排除在候选分支的得分与胜负聚合计算之外；
3. **真实产物持久化**：
   - 每轮迭代独立落盘真实采集到的策略决策轨迹至 `iteration-XXX/strategy_traces.jsonl`；
4. **No-Apply 守则**：
   - 全局主树、梯队、L1 权重与现网部署 100% 保持零改动。
