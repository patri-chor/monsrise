   - 为每个前向候选编译 `ExecutableBranch`，通过 `BranchLibrary.attachExecutableBranchesToEvol` 挂载至 Pilot 分支树；
   - 运行源用例真实完整比赛（`ProductMatchRunner.runFullMatch`），确保分支决策在源用例中准确命中且整体比分非负（`IMPROVES / NEUTRAL`）；
3. **扩展全盘真实产品验证矩阵 (Expanded Product Validation)**：
   - 覆盖源对手同侧（5 个种子：`[1, 7, 42, 100, 2024]`）与非源对手双侧（种子 `[1, 42]`）；
   - 记录基线与分支比分、胜负、逐回合 HP 摘要与分支命中状态；
   - 确认活跃 Pilot 分支在非源用例上零误触、全盘零回归（`activePilotBranches`）；
4. **Warm-Start 战术库沉淀**：
   - 将所有 Local-only 解作为冷启动战术先验保留于 `all2rush_g2_t117_warm_start_library.jsonl`，不参与运行时策略决策；
