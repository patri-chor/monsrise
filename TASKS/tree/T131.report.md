## 1. 任务目标与执行概要 (Mission & Execution Overview)

本任务（T131）确立并实现了 **S 与 D+S 纯谱系优化器及动态快照全流程无缝传播机制 (`S and D+S Lineage Optimizer`)**：
1. **明确优化模式策略 (Policy)**：
   - 优化器循环严格限定为 **S 模式（局部当前回合战术搜索）** 与 **D+S 模式（阵容/徽章调整后接局部战术搜索）** 两种优化模式；
   - 彻底移除开局库（`O` 模式），明确开局库归属于阵型生成，不作为现有阵型周期优化的运行时依赖；
2. **精确动态快照无缝传播 (`Exact Dynamic Snapshot Propagation`)**：
   - 在单一主导优化器（`runGeneration2OptimizerCycle`）及配置接口中引入 `targetSnapshot` 与 `opponentSnapshots` 输入契约（`CycleSnapshotInput`）；
   - 证明并确保整个周期中的 Benchmark、不利局挖掘、局部搜索、前向编译与配对验证均以传入的动态快照对象为唯一真理；
3. **S/D+S 谱系保留与回溯 (`Lineage Frontier & Back-Propagation`)**：
   - 建立 `src/engine/tree/product_training/generation2/cycle/lineage.ts` 模块；
   - S 搜索保存多条非支配代表解谱系（`local_lineages.jsonl`），避免单点早熟收敛；
   - 只有在产生局部 S 提升信号的谱系才进入后续的整局/L2 回溯评估，杜绝无信号 D 的无效算力浪费；
4. **统一证据产物**：
   - 每轮输出 `local_lineages.jsonl`；
   - 阵型目录输出 `lineage_summary.json` 与 `dynamic_snapshot_propagation.json`；
5. **No-Apply 守则**：
   - 全局主树、梯队、L1 权重与现网部署 100% 保持零改动。
