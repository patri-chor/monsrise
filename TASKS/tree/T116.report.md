## 1. 任务目标与执行概要 (Mission & Execution Overview)

本任务（T116）针对 T115 发现的搜索质量短板进行了全面升级，实现了**多样化基线用例选取、真实 1..3 编辑组合搜索、Pareto 支配解筛选与代表解全比赛连贯验证**：
1. **对手多样性基线挖掘 (Diverse Baseline Selection)**：
   - 彻底废弃单一全局严重度排序导致的用例向单一对手聚集问题；
   - 针对 3 大对手（`golden_boom`, `all2prayer`, `gift_jungle`）分别按 `Loss > Draw -> Deficit 降序 -> 早期 Round` 排序，每个对手独立锁定至多 2 个最严重用例（合计 6 个多样化 Case）；
2. **真实 1..3 兼容动作编辑搜索 (Genuine 1..3-Edit Search)**：
   - 依据棋盘可用已部署单位与待定动作动态生成 1、2 或 3 个兼容编辑组合（重定位已部署怪兽、变更待定动作坐标、重排待定放置顺序）；
   - 在生成的 32 预算 Trial 流中真实覆盖 1-edit、2-edit 与 3-edit 候选，杜绝虚假多编辑与同一单位冲突编辑；
3. **联合唯一解集与 Pareto 支配性判定 (Pareto Dominance Calculation)**：
   - 采用 `editedStateFingerprint + observableDigest` 联合唯一标识，保留产生相同结果但棋盘状态不同的战术备选项；
   - 基于胜负结果等级（Win > Draw > HP）、目标血量/存活数、对手血量/存活数计算全量解的 Pareto 支配关系，严格标记 `isDominated` 与支配者 `dominatedBySolutionId`；
4. **Pareto 非支配代表解评选与全比赛验证 (Representative Full-Match Validation)**：
   - 从非支配解集中依据等级、目标血量、对手剩余血量、最少编辑数选出最佳代表解（`isRepresentative`）；
   - 对前向合规表达的代表解进行全比赛连贯执行比对（`ProductMatchRunner.runFullMatch`），记录 `CONTINUATION_IMPROVES / CONTINUATION_NEUTRAL / CONTINUATION_REGRESSES`；
5. **No-Apply 守则**：
   - 全局主树、梯队、L1 权重与现网部署 100% 保持零改动。
