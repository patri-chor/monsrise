## 1. 任务目标与执行概要 (Mission & Execution Overview)

本任务（T124）实现了 **基于真实产品可观测结果与 Score70 驱动的闭环多代迭代优化程序 (`ResultDrivenIterativeRunner`)**：
1. **真实 ProductOutcome 与标准化比较器 (`product_outcome.ts`)**：
   - 提取包含双方胜负、Score70 指标 `(W + 0.70 * D) / N`、逐回合存活数与血量分布的归一化对象；
   - 定义统一比较器 `compareProductOutcome`，彻底杜绝单纯依靠最终原始比分或占位符硬编码判定的漏洞；
2. **严格候选级独立配对评测 (Candidate-Local Paired Decision)**：
   - 区分分支命中（`branchSelected: true`）与未命中用例，仅依据命中实例的 ProductOutcome 进行独立客观决策：
     - `PILOT_ACCEPTED`：命中实例 Score70 严格提升且 0 回归；
     - `PILOT_NEUTRAL`：命中实例 Score70 持平且 0 回归；
     - `PILOT_REJECTED`：存在任何回归或 Score70 倒退立即剔除；
     - `LOCAL_ONLY`：历史单位位移需要更早上下文，不编译运行时前向分支；
3. **闭环迭代 Benchmark 与动态终止**：
   - 每轮迭代前运行当前 Pilot 基准 Benchmark（`baseline_benchmark.json`），迭代后重新执行 Post-Decision Benchmark，记录真实的 `score70Delta` 与胜负比分演进；
   - 下一轮迭代基线完全基于上一轮已接纳的 Pilot 分支动态生成；
4. **No-Apply 守则**：
   - 全局主树、梯队、L1 权重与现网部署 100% 保持零改动。
