## 1. 任务目标与执行概要 (Mission & Execution Overview)

本任务（T115）构建了 **全二冲（All2Rush）完整单回合优化闭环器 (`SingleRoundOptimizer`)**，实现了端到端高内聚单回合优化流程：
1. **单一入口函数 (`runAll2RushSingleRoundOptimization`)**：
   - 暴露于 `src/engine/tree/product_training/generation2/index.ts`，接收目标阵型、对手快照列表、种子列表、最大 Case 数量、搜索种子与预算配置 `[16, 32]`；
   - 返回结构化全量数据对象（选定基线 Case、提案/无效/重复/有效计数、逐预算 Trial 记录、行为独特本地解、代表解及总结）；
2. **基线不利局挖掘 (Adverse Baseline Case Mining)**：
   - 从真实基线比赛中捕获全部可达回合的 `RoundBoardState`；
   - 严格按照 `Loss > Draw -> 目标失分 Deficit 降序 -> 早期 Round` 优先排序，锁定最多 6 个严重度最高的不利回合；
3. **确定性伪随机流候选生成器 (Seeded Candidate Generator)**：
   - 基于 `searchSeed` 驱动伪随机数流，从实际棋盘怪兽与动作中动态生成 1..3 个合法变更（重定位已部署怪兽、变更待定放置坐标、重排待定放置顺序）；
   - 无效提案标记为 `INVALID`，重复状态指纹标记为 `DUPLICATE`，均不消耗执行预算；
   - 仅对有效唯一状态执行单回合权威战斗（`SingleRoundEngine`）；
4. **预算 16 vs 32 对比与解集提取**：
   - 分别对比 16 与 32 唯一有效探索预算下的胜场提升（`ROUND_WIN_IMPROVEMENT`）、平局提升（`ROUND_DRAW_IMPROVEMENT`）与血量存活提升（`HP_SURVIVOR_IMPROVEMENT`）；
   - 提取所有行为独特的改进解，多维度排序选出最佳代表解（`isRepresentative`），并进行前向策略语义表达评估；
5. **No-Apply 守则**：
   - 全局主树、梯队、L1 权重与现网部署 100% 保持零改动。
