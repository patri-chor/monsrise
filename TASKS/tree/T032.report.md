## Product Strategy Contract

`src/engine/play_full_game.ts` now exports an opt-in typed `DeploymentStrategy`:

```ts
(ctx: DeploymentStrategyContext) => DeploymentIntent[]

// Context: side/identity, round, full source team and hand, own/enemy board snapshot,
//          revealed opponent hand, current budget, seed-derived deterministic RNG, product zone.
// Intent:  monsterId, plannedX, plannedY, optional { branchId, branchLabel }.
```

No strategy means the existing greedy/search product behavior remains in place; fixed-seed default compatibility is
covered by T032 Test A. A supplied strategy is declarative only. `playFullGame` alone validates cards and zones,
performs collision relocation, calls `gameEngine.placeMonster`, charges budget, runs combat/reset/scoring, and emits
product trace callbacks.

Product trace fields:

```text
executionSemanticsVersion, round, board side, source side, identity, monster ID,
attempt order, planned/actual coordinates, accepted/rejected + reason,
budget before/charged/after, round observation, branch provenance, outcomes
```

## Tree Strategy and New Call Path

New `src/engine/tree/product_tree_strategy.ts` directly walks `EvolFormation` nodes and selects the most-specific
matching `FeatureMask` branch per round. It outputs product-coordinate intents (the p2-stored tree coordinate is
mirrored inside the adapter for source side 1). It does not import/call `arena.ts`, `playSpecVsSpec`, custom-formation
bundle APIs, or direct placement APIs. Missing branch/node output returns `[]`; it never fabricates a PASS.

Formal call path:

```text
product_path_screen.ts
  -> PersistentSimPool.dispatchTasks(formalRequest=true, executionMode=product_path)
  -> fine_grained_worker.executeProductPathTask
  -> playFullGame(candidate/opponent team, strategyA or strategyB = treeStrategyFor(evol))
  -> product-owned placement / budget / relocation / combat / reset / W-D-L
```

`PersistentSimPool` remains the outer dispatcher. New formal tasks have bounded outer candidate concurrency `<=2`;
inside the run, configured and observed worker concurrency are recorded. The worker retains an explicit
`arena_sandbox_deprecated` compatibility mode for historic sandbox artifacts only. Any `formalRequest=true` using it
throws `DeprecatedArenaFormalError` before workers start.
