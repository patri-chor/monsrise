## 1. 任务目标与执行概要 (Mission & Execution Overview)

本任务（T128）构建并验证了 **动态 T0 阵型池的 L1/L2 跨阵型大乱斗与基准学习优化闭环 (`Dynamic T0 L1/L2 Pilot Cycle`)**：
1. **动态 T0 阵型池模型演进 (`src/engine/tree/product_training/generation2/pool/`)**：
   - 彻底废除将 T0 作为不可变静态锚点的陈旧约束，将 T0 阵型定义为可自我进化、可学习的动态强阵型池；
   - `dynamic_pool.ts` 维护当前动态池状态文件 `current_pool.json`，完整记录演化指纹、L1/L2 评测指标与演化血统；
2. **多层评测体系 (L1 Melee & L2 Benchmark)**：
   - **L1 Melee (`l1_melee.ts`)**：与动态池内其他所有活跃阵型进行双侧多种子全比赛对决；
   - **L2 Benchmark (`l2_benchmark.ts`)**：在正交独立的 L2 测试集上进行全基准比对；
3. **阵型级独立优化编排器 (`t0_pilot_cycle.ts`)**：
   - 自动推举最多 3 套行为异构的 T0 阵型作为 Pilot 目标；
   - 复用统一的单阵型 7 模块收敛优化器（`runGeneration2OptimizerCycle`）执行不利局挖掘、局部搜索与前向验证；
   - 只有在 L1 和 L2 均无回归且组合 Score70 严格提升的情况下，才允许将改进后的候选阵型快照写回动态池；
4. **统一 CLI 与证据产物**：
   - 提供 `scripts/run_dynamic_t0_l1_l2_pilot.ts` CLI 脚本；
   - 输出完整批次与逐阵型产物至 `reports/tree-cycle/dynamic-t0-l1-l2-pilot/<run-id>/`；
5. **No-Apply 守则**：
   - 全局主树、梯队、L1 权重与现网部署 100% 保持零改动。
