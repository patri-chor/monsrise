# T052 报告：统一爬山局部变异与条件分支归纳 (Unified Hill-Climb and Conditional-Branch Learning)

> **领域**: `tree` | **执行分支**: `agent/tree`
> **目标**: 将局部爬山变异与条件分支归纳统一到正规产品路径搜索闭环中。当一个局部变异体在特定可观测弱项对手/流派上获得显著提升、但大盘总分因过度特异化而退化或持平时，绝不盲目丢弃，而是自动提取其最小可观测 `FeatureMask`，将其转化为条件分支候选并挂载到合法分叉节点；同时支持分支局部子树优化与前移分叉节点安全验证。

```text
                      [ 局部变异 (Spatial / Order / Branch / Policy) ]
                                            │
                                            ▼
                      [ 产品路径标准对战评测 (Score70 & W/D/L) ]
                                            │
                      ┌─────────────────────┼─────────────────────┐
                      ▼                     ▼                     ▼
             [大盘全面显著提升]      [大盘退化/持平, 但特定弱项]      [全局与局部均无提升]

                                      转化为条件分支挂载)
                                            │
                                            ▼
                                  [分支子树聚焦局部优化]

```

## 2. 核心模块与四态路由模型落地

核心实现模块位于 [`src/engine/tree/product_training/t052_branch_routing.ts`](file:///d:/develope/monsrise1/src/engine/tree/product_training/t052_branch_routing.ts)：

### 四态路由定义 (`RoutingDecisionType`)
1. **`GLOBAL_IMPROVEMENT`**：大盘总分 $\Delta \text{Score70} > +0.005$，全局显著提升，直接替换/推进主干；
2. **`LOCAL_ONLY_BRANCH`（核心闭环）**：大盘总分持平或轻微退化（在容忍度 $\le 0.05$ 内），但针对某个可观测弱项对手/流派取得显著增益（$\Delta \text{Score70} \ge +0.10$），**自动推导最小解释 `FeatureMask` 并转化为条件分支候选挂载到分叉节点，主干保持不变**；
3. **`NO_INFORMATIVE_GAIN`**：全局与局部均无显著突破，保留为拒绝审计记录；
4. **`INVALID`**：非法坐标、算子碰撞或不可见特征泄露。

## 3. 最小可观测标签推导与端到端分支转化案例

### 1) 最小解释标签推导 (`inferMinimalFeatureMask`)
- 基于真实产品战局中观测到的对手特征（对手手牌 ID、关键怪 ID、主标签、附加标签、先后手）；
- 遵循**最小特异性原则（Minimal Specificity）**：
  $$\text{关键怪 (Keys)} \longrightarrow \text{主标签 (Main)} \longrightarrow \text{附加标签 (Subs)} \longrightarrow \text{先后手约束 (Side)}$$
- 严禁未来信息泄露：若特定关键怪（如矿爆 `mine`）在开局手牌中不可见，则绝不生成该条件。

### 2) 端到端实测案例
- **亲本**：`golden_boom` 主力阵型，遭遇 `mine_fullrush`（全冲矿爆流）时胜率极低（5胜/13负，Score70 = 0.320）；
- **变异体**：微调前排站位以规避矿爆范围，由于站位前压，大盘总分略有微降（从 0.770 降至 0.745，$\Delta = -0.025$）；
- **路由决策**：命中 `LOCAL_ONLY_BRANCH`（针对 `mine_fullrush` 胜率提升至 14胜/4负，$\Delta = +0.450$）；
- **自动转化**：在 Round 1 挂载条件分支 `keys: ['mine']`，主干保持默认布局，成功实现“遇矿爆自动切克制站位，遇其他对手走稳健主干”。

## 4. 分支局部优化与前移分叉测试机制

1. **分支局部优化 (`optimizeBranchSubtreeLocally`)**：
   - 仅对子分支内部的站位与出怪时序进行聚焦优化微调（如 `shift_y` 或 `swap_placement`）；
   - **硬性安全保证**：主干 main 根节点与其默认站位完全隔离、严禁篡改。
2. **前移分叉节点验证 (`evaluateForwardBranchNode`)**：
   - 尝试将 Round 2 发现的分支条件提前至更早的回合（Round 1）；
   - **准入准则**：仅当该条件在目标更早回合**完全可合法观测**且不引发早期算力/站位冲突时，才允许安全前移；否则拒绝前移并记录具体审计理由。
