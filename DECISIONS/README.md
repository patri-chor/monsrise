# DECISIONS — 多会话协作黑板

本目录是 **决策会话（Senior）与落地会话（Implementer）之间的文件协议**。
两个独立会话共享同一工作区，通过这里交换决策与结果，实现"高级 AI 决策、另一个 AI 落地"。

## 文件协议

每个任务一个编号前缀，例如 `T001`：

| 文件 | 谁写 | 内容 |
|---|---|---|
| `T001.md` | 决策会话 | **任务规格**：目标、约束、方案与权衡（A/B/C + 推荐）、验收标准、优先级、涉及文件 |
| `T001.report.md` | 落地会话 | **落地报告**：完成内容、改动文件清单、测试结果、遗留问题、偏离说明 |
| `T001.closed.md`（可选） | 决策会话 | 复盘：验收结论、遗留问题是否转新任务、经验教训 |

状态写在文件首行：`STATUS: OPEN | IN_PROGRESS | DONE | REJECTED`

## 协作流程

1. **决策会话**：分析问题 → 写 `Txxx.md`（含方案权衡与验收标准）→ 告诉用户"已下发任务 Txxx"
2. **落地会话**：读 `Txxx.md` → 按验收标准实现 → 写 `Txxx.report.md`（STATUS: DONE 或说明偏离）→ 告诉用户"Txxx 完成"
3. **决策会话**：读 `Txxx.report.md` → 验收 → 写 `Txxx.closed.md`；验收不过则更新规格重发
4. 会话之间**通过文件同步状态**，不靠口头传递

## 规则

- 文件名用任务编号，不要用中文名（避免跨平台编码问题）
- 每份文件开头必须有 `STATUS:` 行
- 落地会话发现规格有歧义 → 在 report 里写"规格疑问"，不要擅自假设
- 决策会话看到疑问 → 更新规格文件后回复
