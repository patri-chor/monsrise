# Dual-Domain Protocol Reference

## 目录与文件对应规范

1. **`TASKS/` (Root)**
   - 任务文件：`TASKS/Txxx-*.md`
   - 报告文件：`TASKS/Txxx.report.md`
   - 决策文件：`TASKS/Txxx.closed.md`

2. **`TASKS/tree/` (Tree 优化域)**
   - 任务文件：`TASKS/tree/Txxx-*.md`
   - 报告文件：`TASKS/tree/Txxx.report.md`
   - 决策文件：`TASKS/tree/Txxx.closed.md`

3. **`TASKS/generation/` (新阵型生成域)**
   - 任务文件：`TASKS/generation/Txxx-*.md`
   - 报告文件：`TASKS/generation/Txxx.report.md`
   - 决策文件：`TASKS/generation/Txxx.closed.md`

## 状态标识规范
- 任务文件：`STATUS: OPEN`
- 报告文件：`STATUS: DONE` 或 `STATUS: PARTIAL`
- 决策文件：`STATUS: DONE` 或 `STATUS: REJECTED`
