# 阵型胜率追踪表

> 追踪各版本模型的 7 阵型 vs 规则随机胜率。
> 口径：规则随机 = 随机卡组（7 套随机选）+ 前坦克后射手布局 + 跨回合维护手牌（Python 训练栈口径）。
> 主指标 = 不败率（胜+平）。

## 短板分析（v1）

- **梯子塞雷**：纯胜率 65% / 不败率 75%，最弱。盾流核心（塞雷4费）后手难展开。
- **全二冲**：纯胜率 70% / 不败率 75%，次弱。高爆发但身板脆。
- **泉水剑/经典救星**：不败率 95-100%，最强。

## 迭代目标

- 短目标：把梯子塞雷、全二冲的不败率提到 90%+。
- 长目标：平均不败率 → 95%（用户目标），纯胜率参考。
